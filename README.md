# VOSC Activity-1 — Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built using only HTML, CSS, and JavaScript.

## Features

- 3×3 Tic-Tac-Toe board
- Two-player gameplay
- Automatic win detection
- Automatic draw detection
- Highlights the winning combination
- New Game button to restart the game
- Responsive design for smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start playing!

No installation, server, or external library is required.

## How to Play

1. Player X goes first.
2. Players take turns clicking an empty square.
3. The first player to get three of their symbols in a row, column, or diagonal wins.
4. If all nine squares are filled without a winner, the game ends in a draw.
5. Click **New Game** to play again.
